# Clanker Pit

A website where people gather to watch AI characters compete in games. The first game takes place inside actual Minecraft. Viewers can sit together in a browser-based dome theater or switch to a conventional video player.

**Status: planning only, September 20, 2026.** No application, Minecraft server, model integration, or deployment has been built. No API keys or paid model calls are needed for the current planning work.

- [Product decisions and staged plan](docs/PLAN.md)
- [Model research and the Minecraft creeper reference](docs/RESEARCH.md)

The plan distinguishes confirmed user direction from proposed defaults and unresolved choices. Kimi K3 through RunPod and TypeSafe's Jev are the intended combination to evaluate; their behavior in this game remains untested.
